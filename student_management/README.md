# 学生信息管理系统

## 项目简介

基于 C++ 面向对象思想和 CMake 构建系统实现的命令行学生信息管理系统。

## 目录结构

```text
student_management/
├── include/                 # 头文件目录
├── src/                     # 源文件目录
├── CMakeLists.txt           # CMake 构建配置文件
└── README.md                # 本说明文档
```

## 运行方法

编译并运行程序：

```bash
cd student_management
mkdir build
cd build
cmake ..
make
./bin/student_doc_system
```
